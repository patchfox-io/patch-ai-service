# What does PatchFox provide?

* The means of managing all of your dependencies, all at once, with ease.

* Top line metrics regarding collections of code projects at every commit to every build file. These metrics include measures like Redundant Package Score (RPS) and Patch Efficacy Score (PES) which measure the overall effectiveness of an organization's dependency management program. 

* Wholistic tracking of every change to every dependency graph in every repository. When findings came onto the books, for how long were they on the books before they were being patched, etc. 

* The ability to prevent findings from showing up in the first place. 

* Recommendation lists, in order of most to least impactful towards improving one or more metrics for a collection, that represent the fastest possible path towards meeting a specific dependency management business goal.
